# Taller1-P1-DjangoProject

A small Django web application that shows a catalog of movies (title, description, poster image and an optional link). Visitors can search the catalog by title, and movies are added and edited through the Django admin site. The project was built as a Django exercise: its repository name suggests a course assignment ("Taller 1, Part 1"), and the code is a minimal, learning-oriented setup rather than a production service.

Despite the name of the Django project (`moviereviews`), the app does not implement reviews or ratings. It only lists and searches movies.

## Features

- Home page (`/`) listing every stored movie as a card with poster image, title, description and, when set, a "Movie Link" to an external URL.
- Case-insensitive search by title through the `searchMovie` query parameter (for example `/?searchMovie=harry`).
- About page (`/about/`) with static content.
- Movie management through the Django admin (`/admin/`), where the `Movie` model is registered.
- Uploaded poster images are served from `/media/` (only when `DEBUG` is enabled).

## Tech stack

- Python 3 (the committed bytecode files are `cpython-38`)
- Django 2.2 (the migration header reports Django 2.2.12)
- Pillow (required by Django's `ImageField`)
- SQLite (`db.sqlite3`)
- Bootstrap 5.3 (loaded from a CDN on the home page)

## Project structure


## Getting started

There is no `requirements.txt`, Dockerfile or Makefile in the repository. The commands below are based on the code and on the migration header (Django 2.2.12).

```bash
# 1. Create and activate a virtual environment
python3 -m venv venv
source venv/bin/activate

# 2. Install the dependencies
pip install "Django==2.2.12" Pillow

# 3. Apply the migrations (db.sqlite3 is already included, so this is optional)
python manage.py migrate

# 4. Create an admin user to add movies
python manage.py createsuperuser

# 5. Start the development server
python manage.py runserver
```

Then open http://127.0.0.1:8000/ for the catalog, http://127.0.0.1:8000/about/ for the about page, and http://127.0.0.1:8000/admin/ to add movies.

## Configuration and security

The settings in `moviereviews/settings.py` are the defaults generated by `django-admin startproject`, meant for local development only:

- `DEBUG = True`
- `ALLOWED_HOSTS = []`
- SQLite database stored in the project directory

Before any deployment, the secret key should be moved out of the source code (for example into an environment variable), `DEBUG` should be turned off, and `ALLOWED_HOSTS` should be set.

## Tests

`movie/tests.py` contains only the default placeholder, so no automated tests are implemented yet. Run them with `python manage.py test` (this runs without errors but executes no test cases).
